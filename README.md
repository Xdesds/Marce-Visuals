# Marce Visual

Клиентский мод для Minecraft Java **1.21.11**, Fabric Loader **0.18.4+** и **Java 21**.

## Запуск и сборка

- `.\gradlew.bat runClient` открывает игру из проекта с нужными зависимостями.
- `.\gradlew.bat build` собирает `build/libs/marce-visual-0.1.0.jar`.
- Для обычного лаунчера положите этот JAR, Fabric API для 1.21.11 и Fabric Language Kotlin 1.13.9 или совместимую версию в папку `mods` профиля Fabric 1.21.11.

## Управление

Войдите в мир и нажмите **правый Shift**, чтобы открыть меню. Клавишу можно поменять в настройках управления Minecraft. **Esc** закрывает меню.

- **HUD** управляет Dynamic Island, FPS, пингом, музыкой и уведомлениями. В одиночной игре пинг показывает задержку локального соединения.
- Нажатие на логотип плавно расширяет панель категорий и показывает их названия. Повторное нажатие сворачивает её.
- **Function → Shader Hit Color** включает четыре эффекта на модели цели: **Pulse** (цветовой импульс), **Aurora** (переливы), **Shock** (бегущие кольца) и **Crystal** (светящиеся грани). В настройках **…** отдельно задаются эффект и палитра обычного удара, крита и комбо, а также длительность и интенсивность. Комбо считается по одной цели с промежутком до 1,2 секунды; его порог настраивается. Крит имеет приоритет над комбо. Эффект появляется после подтверждения урона у атакованной цели.
- **Function → Custom Hitbox** показывает визуальные границы живых существ. **Vanilla** рисует обычную рамку, уровень глаз и направление взгляда. **Wave** использует анимированные волнистые линии с мягким свечением. Через **…** настраиваются палитра, толщина, амплитуда, Glow и фильтр игроков. Отрисовываются до 16 ближайших видимых существ в радиусе 24 блоков; размеры коллизий и дистанция атаки не меняются. Обе функции по умолчанию выключены.
- **HUD → Track layout** переключает показ трека. **Inline** заменяет показатели и логотип музыкой внутри островка. **Separate** показывает трек отдельной плашкой под островком.
- Кнопка **…** открывает настройки модуля поверх меню. Из настроек **GUI Settings** можно открыть палитру акцентного цвета, а в **Now playing** изменить интенсивность волн.
- **GUI Settings** содержит акцентный цвет, готовые палитры и переключатели градиента, анимации и зерна. Оттенки градиента следуют за акцентом, движение реагирует на курсор и клики внутри меню.
- **GUI Settings → Discord RPC** включает Discord Rich Presence: Marce Visual, Minecraft 1.21.11, состояние меню/одиночной игры/мультиплеера и время сессии. Включён по умолчанию. Нужен запущенный настольный Discord с разрешённым отображением игровой активности. Подключение работает в фоне и восстанавливается после перезапуска Discord; при отключении RPC статус очищается. Используется только публичный Application ID, без секретов и OAuth. Адрес сервера, имя мира и игровой ник в статус не передаются. [Документация Discord RPC](https://github.com/discord/discord-rpc/blob/master/documentation/hard-mode.md).
- Шестерёнка внизу левой панели открывает **GUI Settings** рядом с кнопкой. **Jelly opening** включает упругое появление меню, настроек модуля и палитры.
- **Track layout** использует упругий сегментный переключатель. Можно нажать **Inline / Separate** или перетащить светлый бегунок.
- Настройки сохраняются в `config/visual-client.json`.
- **GUI Settings → Discord RPC** включает статус Marce Visual в настольном Discord: версию Minecraft, главное меню / одиночную игру / мультиплеер и время текущей сессии клиента. RPC включён по умолчанию, подключается локально и восстанавливается после перезапуска Discord. Адрес сервера, имя мира и ник в статус не передаются. Для подключения используется только публичный Application ID `1293983298254671995`, без Client Secret или токена. [Протокол Discord IPC](https://github.com/discord/discord-rpc/blob/master/documentation/hard-mode.md).
- Dynamic Island прилегает к верхней кромке экрана. Когда появляется полоса босса, островок отскакивает под неё и скругляет верхние углы. Уведомления временно увеличивают его высоту.
- При входе в мир Dynamic Island собирает планету из двух половинок, прокручивает кольцо и выводит приветствие с игровым ником. Интро занимает около 2,3 секунды.
- **Now playing** на Windows показывает обложку, название трека и исполнителя. При паузе или остановке карточка трека исчезает. Визуализатор обрабатывает звук музыкального процесса блоками по 10 мс. Низкие частоты 32–150 Гц задают широкую волну, а атаки ударов добавляют короткие толчки. Если захват потока недоступен, края реагируют на пики громкости приложения. Браузерные медиасессии игнорируются. [Windows Media Control](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager) · [WASAPI Process Loopback](https://learn.microsoft.com/en-us/samples/microsoft/windows-classic-samples/applicationloopbackaudio-sample/)

## Рендер

[VisualDraw](src/main/java/dev/visual/client/VisualDraw.java) рисует панели Luma и поверх них запускает [MSDF-рендер](src/main/kotlin/dev/visual/client/MsdfDraw.kt). Экран и HUD используют Inter SemiBold и Material Symbols Rounded с весом 700 и заливкой. Атлас текста включает латиницу, кириллицу и базовые знаки пунктуации.

[IslandBlur](src/main/kotlin/dev/visual/client/IslandBlur.kt) копирует участки игрового кадра под островком, меню и палитрой и размывает их в пределах скруглённых панелей. Радиус верхних углов островка меняется во время отскока от верхней кромки.

PNG-атласы и метрики JSON входят в JAR. Для обновления глифов используется `tools/generate-msdf.ps1` с `msdf-atlas-gen` 1.4 и исходными variable TTF. [Генератор](https://github.com/Chlumsky/msdf-atlas-gen/releases/tag/v1.4) · [Inter](https://github.com/google/fonts/tree/main/ofl/inter) · [Material Symbols Rounded](https://github.com/google/material-design-icons/tree/master/variablefont)

```powershell
.\tools\generate-msdf.ps1 -Generator path\to\msdf-atlas-gen.exe -Inter path\to\Inter.ttf -MaterialSymbolsRounded path\to\MaterialSymbolsRounded.ttf
```

Исходники Luma (OpenGL) взяты из ветки [legacy](https://github.com/evaware-dev/Luma/tree/d518dd848082a00ade4857f6c0abb5ce567089a9) и собираются вместе с модом. Лицензия находится в [vendor/luma/LICENSE](vendor/luma/LICENSE) и включена в JAR.
